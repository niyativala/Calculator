# 🧮 Simple Calculator

A clean and responsive calculator built using **HTML, CSS, and JavaScript**.
This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Features
- Basic arithmetic operations (+, -, *, /)
- Clear display (C button)
- Backspace (⌫) functionality
- Decimal support (.)
- Modern UI design

## 🛠️ Technologies Used
- HTML
- CSS (Grid + Styling)
- JavaScript (DOM Manipulation)

---

## 📂 Project Structure

index.html → Calculator UI structure  
style.css → Styling and layout  
script.js → Calculator logic and functionality  

---

## ⚙️ How It Works

1. Click on number buttons  
2. Select an arithmetic operator  
3. Enter the next number  
4. Press `=` to calculate the result  
5. Use `C` or `AC` to clear the display  

---

## ▶️ How to Run Project

1. Download or clone this repository
2. Open `index.html` in your browser
3. Start calculating 🧮

---

### 📊 Project Logic (Simple)

* User inputs numbers using buttons  
* JavaScript stores the entered values  
* Selected operator performs calculation  
* Result is displayed instantly on screen
